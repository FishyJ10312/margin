# 留白 0.6.2：ChatGPT 账户分析配框

用户选择的分工已实现：照片分析、参数配框和一轮精修可通过 ChatGPT 账户授权；手绘生图默认继续使用本机 Codex。两条入口独立，不把账户授权令牌用于 Images API，也不自动切换计费方式。

## 使用

1. 导入照片，打开“根据照片智能配框”。
2. “使用的模型入口”选择“ChatGPT 账户 · 无需 API Key”。
3. 点击 **Continue with ChatGPT**，在系统浏览器的 OpenAI 官方页面登录、选择工作区并确认套餐用量授权。留白不接收账户密码。
4. 回到留白，选择服务器为此账户列出的模型；也可刷新列表、添加另一账户、重新登录或断开当前连接。
5. 查看已展示的缩略图、画布信息和设计方向，勾选确认后生成三套建议。选择、应用或保存模板。精修入口则只分析一轮并返回一套方案。

登录本身不发送照片。模型请求仅发送已展示的最长边 768 px 缩略图；精修额外发送不含署名的当前配框缩略图。原照片仍由本机合成，模型不执行本机命令。

## 授权和额度

采用 OpenAI 官方公开客户端授权流程：系统浏览器、PKCE、每次独立的 state / nonce、仅监听 127.0.0.1 的临时回调端口。首次注册得到的客户端 ID 与验证后的账户身份单独保存；邮箱相同的不同工作区不会混用凭据。

仅有身份登录不代表可以使用套餐。软件检查实际授予的权限，缺少套餐用量授权时禁用分析。可用性仍受 ChatGPT 套餐、工作区政策、地区和应用接入资格影响。这是按官方开源客户端协议实现的接入，不代表本应用已经取得商用合作资格；未擅自公开或重新授权项目源码。

手绘 PNG 生成不经过此授权通道。Codex 使用现有 CLI 登录；原有图像 API 入口仍使用独立 API Key 和 API 项目额度。任何失败都不会自动转向另一种额度来源。

## 保存、刷新和断开

- OAuth 令牌仅由 Rust 后台使用，保存在 macOS Keychain / Windows Credential Store，不返回界面、不进入模型设置、模板、日志或源码包。Windows 凭据的小容量限制采用分段条目和提交清单处理。
- 本机账户记录只包含连接标识、显示标签和状态。Unix 上目录权限 0700、记录文件 0600；通过临时文件提交。
- 同一时间串行刷新授权，替换访问令牌和轮换的刷新令牌。取消分析不会中断已经开始的凭据提交，避免下一次误用旧刷新令牌。
- 临时网络错误保留连接；明确失效的刷新授权会禁用该连接并要求重新登录。不会循环登录或自动重发分析。
- 断开连接会停止当前分析、尝试向官方撤销可续期会话，并清除本机凭据。远程撤销未确认时会明确提示，可在 ChatGPT 用量设置中断开应用。保留非敏感注册映射供以后重新登录。

## 请求与流畅性

按当前账户读取模型目录，保留官方顺序和显示名。分析走公开 Responses API，使用 `store: false`、`stream: true`，不调用图片生成工具或额外工具。只有收到完成事件才接受结果；流中出现用量错误、中断或不完整响应均不应用半成品。

模型输出仍经过原有颜色、元素数量和几何边界验证。请求、回调、响应和输出都有超时或体积上限。网络等待不阻塞界面；授权只增加少量元数据和系统凭据，不引入 Node、Python 或本地模型运行时。

## 本轮验证边界

本地 OAuth 模拟服务实际走 HTTP 回调、代码交换、RSA 签名身份验证、账户模型目录、Responses 流式分析、刷新和撤销；与真实 OpenAI 账户授权区分。浏览器界面回归使用模拟原生调用。Mac 系统钥匙串使用随机临时测试条目，完成大凭据的写入、读取和删除。

本轮没有代用户登录真实账户，没有在官方页面确认套餐授权，没有发送私人照片或消耗真实模型用量。官方账户授权和实际云端分析需用户在新软件中完成后验证。Windows 的凭据实现已经接入，Windows 构建与实机验证仍未进行。
