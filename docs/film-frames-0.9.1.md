# 胶片外框 · 0.9.1

“边框模板 → 胶片”共 12 款。保留胶片边界、黑金底片、暖白相纸；新增 35mm 全幅扫描、彩负暖边、黑白底片扫描、120 中画幅、16mm 电影胶片、Super 8 单孔、暗房接触印样、纸质幻灯片框与拍立得相纸。

这些是原创程序绘制的模拟外框，不是下载的真实扫描素材，也不调用 AI。参考真实扫描和摄影软件的片边语言，使用圆角孔洞、微字、片号、细微颗粒和不规则片边形成不同外观。片号是固定装饰，非照片的拍摄参数。完整保留输入照片的颜色与像素，不在照片里制造颗粒、漏光或文字，不因外框裁切或拉伸照片。幻灯片和拍立得用外框内的一层纸卡形成相纸轮廓；照片在最终画布中仍居中。

扫描款的颗粒和片边标记在“调整模板细节”中设置，保存到个人模板后保留；原有保存文件可继续加载。拍立得相纸没有片号，因此只显示颗粒调节。用户当前的画布比例和边框宽度默认保持。不同长宽比下，这是依据照片开口自适应的外观模拟，不是按物理毫米复刻的某个品牌胶卷。

留白小于照片短边约 5% 时，齿孔和片边字已经小到像噪点，因此不再绘制，只保留干净的片边，相当于裁得很紧的扫描。“胶片边界”的齿孔贴着照片排布，竖图会转到左右两侧；固定画幅多出来的空间保持干净。

横版、竖版、方形和加比例画幅的验收板可以用 `MARGIN_BOARD_DIR=<目录> cargo test --lib template_board -- --ignored` 生成；`every_template_keeps_the_photo_opening_untouched_in_every_orientation` 会检查全部模板在这些画幅下都不覆盖照片像素。

处理只遍历边框区域，按小矩形绘制孔洞和微字；不分配整幅 RGBA 遮罩或附加扫描素材。颗粒用固定种子及全局坐标，整幅导出与局部水印预览保持相同像素结果。缓存仍沿用单张原图／预览代理，批量任务仍逐张执行。
