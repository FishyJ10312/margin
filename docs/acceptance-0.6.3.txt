边界
本轮没有重新授权真实 OpenAI / Claude / Copilot / OpenRouter 账户，也没有真实云端分析、生图或额度扣减验收。未上传私人照片、未消耗模型额度。各服务商真实登录与推理仍需对应账户实际验证。Pi 模型目录仅是 SDK 目录；可用性由服务商与账户权限决定。
Pi 与 Node 为可选外部组件，Pi 登录/退出会影响本机 Pi 的同一服务连接；退出仅清理本地共享连接，不承诺远端撤销。请求不自动重试或计费回退，取消后已发出的请求仍可能计入用量。
既有真实 Codex 生图和 GUI 批量导出记录属于 0.6.0 的历史验收。Windows 本轮未构建或实机操作。
