# 留白 0.6.3 模型配置

右上角“模型配置 / Model configuration”可在没有照片时打开。选择服务、完成服务商浏览器授权、选择视觉模型，点击“保存为照片分析模型”。保存本身不发送照片或启动推理。之后打开“根据照片智能配框”或“精修一次”，核对缩略图、设计方向、服务和模型，勾选发送确认再生成。

## 可用入口

| 入口 | 授权与用量 | 用途 |
| --- | --- | --- |
| Pi · OpenAI / ChatGPT | Pi 管理的 OpenAI OAuth，ChatGPT 订阅用量 | 分析配框、精修 |
| Pi · Claude Pro / Max | Pi 管理的 Anthropic OAuth，Claude 订阅用量 | 分析配框、精修 |
| Pi · GitHub Copilot | Pi 管理的设备授权，Copilot 套餐用量 | 分析配框、精修 |
| Pi · OpenRouter | OpenRouter OAuth 账户授权，账户余额 | 分析配框、精修 |
| ChatGPT · 官方账户 | 既有原生 OAuth，凭据保存在系统凭据库 | 分析配框、精修 |
| 本机 Codex | 既有本机登录 | 分析配框、精修 |
| 兼容视觉 API | 自己的 Base URL、模型、会话 API Key | 分析配框、精修 |
| 图像生成 | 本机 Codex 或独立 GPT Image API Key | 一张透明手绘 PNG |

模型目录仅显示支持图片输入的模型，可按名称或 ID 搜索；模型出现在 Pi 目录中不代表当前套餐一定有调用权限。实际可用性、计量和访问限制由服务商决定。连接失败不自动切换服务、模型或 API 计费。

## Pi 授权如何工作

实现参考 [Pi AI README](https://github.com/earendil-works/pi/blob/main/packages/ai/README.md) 的 provider、CredentialStore、OAuth 和 Models 接口。留白只按需启动一个临时 Node 进程，加载本机 Pi 的 AI SDK、所选服务商适配器以及凭据存储模块；不会执行 Pi coding-agent 循环、AGENTS、扩展、MCP、shell 或模型工具。模型只收到经用户确认的缩略图和设计要求，返回的设计继续经过本机白名单、尺寸、元素数量等校验后绘制。

本机验证组合为 Pi 1.5.2 / Node 24.16.0。Pi 和 Node 都是可选外部组件，不随留白打包，不自动安装或下载本地模型；照片加框、水印、模板和批量导出不依赖它们。找不到时可展开“Pi 程序设置”选择现有 Pi 程序，或打开官方安装说明。Mac 自动检查 PATH、常见安装位置和 nvm；Windows 支持 PATH 与用户 npm 路径，但本轮尚未进行 Windows 实机验证。

Pi 连接与本机 Pi 共用授权。这里登录、重新登录或退出同一服务，也会影响 Pi 自己的连接。退出是本机共享连接的清除，不等于远端撤销；远端授权管理请使用服务商官网。原生 ChatGPT 入口的账户记录与 Pi 相互独立。

浏览器授权由 SDK 负责，留白只接受固定服务商的 HTTPS 授权域名；模型界面只接收状态、主机名、设备码和待完成的授权步骤，不接收 OAuth 访问或刷新令牌。账户密码在服务商官网输入，界面中的授权输入框只用于授权码或回调链接。OpenAI 使用本机持久设备标识。SDK 的凭据轮换通过 Pi 自身的锁定存储提交；调用方关闭或取消时先通知子进程，等安全边界结束，超时后才终止。服务端已发出的请求仍可能计入用量。

订阅入口关闭环境 API Key 回退。OpenAI、Claude 和 Copilot 必须是 OAuth；Pi 中保存的 API Key 不会被当作订阅使用。OpenRouter 的授权按 SDK 设计得到账户 Key，因此单独显示“账户余额”。兼容 API 的 Key 只保留在本次软件内存中，更换地址来源会清空，不写入模型配置或模板。图像生成和照片分析的模型设置彼此独立。

## 稳定性与验证边界

Pi 任务一次只运行一个；输出按行及总量限额解析，SDK 错误转为固定提示。不会把原始模型服务错误或凭据写到界面。未完成或中断的模型回复不作为设计采用；不自动重试。只读“检查授权与模型”不刷新令牌、不启动模型请求。

本轮自动化验证使用合成图片、假 SDK、假凭据及本地测试服务。实际 Mac 会检查既有 Pi 授权状态、模型目录和配置保存；没有重新登录或退出真实订阅，没有发送私人照片，也没有进行真实云端分析或额度扣减验收。各服务商的真实登录与推理需要对应账户实际授权并试用后确认，不能以目录读取代替。

Mac 交付包采用临时签名，尚未 Apple 公证。Windows 本轮没有构建和操作验收。
