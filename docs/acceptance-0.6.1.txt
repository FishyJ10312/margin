本轮新增
- 独立 GPT Image API 生图入口，图像模型与视觉配框模型分开配置。可选择预置模型、读取接口模型列表、手填模型 ID，选择质量与画布尺寸。
- 无参考走 /images/generations，有参考走 /images/edits；明确提交所选模型，每次一张透明 PNG。结果进入原有素材校验、归档、装框和模板复用流程。
- Key 只存本次内存，不写配置或来源记录。接口主机变更时清除旧 Key；禁用重定向、远程 HTTP 和 URL 内嵌凭据。服务端错误正文不直接展示。
- 沿用单任务、取消、超时和响应体积限制；图片解码归档在后台执行，不自动重试或回退付费服务。
