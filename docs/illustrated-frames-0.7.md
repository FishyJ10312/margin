# 留白 0.7 · 整幅艺术边框

进入“根据照片智能配框 → 艺术边框”，保留默认“整幅艺术边框”，选择“丰富”并写下风格方向。模型会参考当前照片的主题、色彩、构图，以及最终比例和真实留白。确认后才发送去除原始元数据的缩略图。每次生成一幅，先看完整效果，再应用或保存为模板。独立手绘素材用于给原有边框添加一组装饰；线条与几何方案用于较轻的可编辑矢量设计。

图像生成使用模型配置中的“手绘生图”入口，默认是本机 Codex 的现有登录与生图用量。图像模型由 Codex 内置工具管理。直连 GPT Image API 使用用户单独配置的图像模型与该 API 额度。原生 ChatGPT 分析授权与 Pi 订阅接入保持独立；不会失败后自动改用其他账户、服务或 API 额度。

生成的 PNG 由应用保管。照片像素由本机读取和合成，模型画出的任何中心内容都不能覆盖原照片。原比例使用连续映射，避免分块舍入造成细缝；其他比例把插画按四边与四角等比铺满，边缘图案可能裁切。保存模板、预览、切换照片与导出不会再次调用模型。模板保存比例、边框和插画；不包含照片源文件、个人署名或模型凭据。

“精修一次”会参考照片与当前配框两张缩略图，根据文字要求重新绘制整幅插画，可以调整图案形状、大小、位置和布局。它使用一次新的图像生成请求，精修完成后显示前后对比，选择应用后才改变当前边框。矢量方案仍走原有矢量精修。

渲染只保留一张照片缓存和至多两张、最长边 2048 的插画缓存，直接合成到 RGB 输出或局部预览；不会为了整幅艺术边框额外建立全尺寸 RGBA 叠加层。预览、导出、水印局部查看使用相同合成核心。模型请求保留单任务锁、取消、超时和输出大小限制；没有自动重试。
