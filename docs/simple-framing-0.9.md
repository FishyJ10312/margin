# 0.9 · 模板直接用，AI 从照片出发

主界面保留两个边框入口：

- **边框模板**：21 款本地设计，包含胶片边界、黑金底片、暖白相纸三种胶片展示方式。选中先预览，应用后才修改设置，不发起分析或生图请求。细节调整折叠；保留当前比例与留白的选项仍可见。
- **AI 设计**：照片缩略图、自由描述（可选）、当前模型和生成按钮。无需选择风格卡；描述留空时，根据照片内容、构图、色彩自主设计。“更多选项”可指定布局、配色、密度，并切换完整生图、可编辑图形或独立装饰素材。默认布局和密度为自动。

所有模型连接只在“模型配置”维护；从设计页更换模型时保留当前描述和生成方式。编辑描述或可选限制后须重新确认发送。模型仅在确认并点击生成后调用，生成后由用户选择应用或保存。

主界面的保存、预设和边框图层细节默认折叠；现成模板不再显示 AI 精修入口。已生成的作品继续提供一次精修及前后对比。旧模板、照片、预设、语言选择均沿用；旧风格枚举为兼容历史文件保留，但新设计请求使用自动风格，避免界面已无选择项却仍被历史设置限制。

本次增加 UI 隔离验收，覆盖空描述、历史胶片配置迁移、可选布局、重新确认、更换模型返回、ChatGPT 连接复用、无额度的本地模板、精修与中英文。模型回复使用测试替身，不代表本次进行了真实生图或验证了模型创作品质。Rust 图形合成与导出另行验证横、竖、方图的照片区域保护和预览局部一致性。
