# 留白 0.8：样式选择与对齐

“选择边框样式”可浏览 19 种本地设计，新增摄影画廊、双层卡纸、细线双框、胶片边界、现代色带、几何角构、条纹纸边、拼贴纸角。默认保留当前照片比例和边框宽度；取消勾选可使用模板自身的版式。底色、三种装饰色、强度、图案尺寸可调。键盘上下方向键可切换，同一张真实照片实时预览，支持对比原效果。点击“应用所选样式”才修改主画面；关闭窗口不会应用。水印、导出设置和原照片保留。

本地选择不调用模型。预览只运行一项任务，最多等待一项最新任务；旧结果不会覆盖新选择。使用现有代理图、Rust 合成与两项 PNG 缓存，不增加运行依赖。

“AI 自定义设计”先选择现代平面、摄影装帧、复古胶片、克制线稿、纸片拼贴、轻绘插画或自由描述。高级选项包括对角／四边／底部布局，照片配色／黑白／自定义三色，以及默认关闭的纸张纹理。自由描述需要填写补充要求。风格约束同时用于初次生成与整幅边框精修，避免旧版海岸插画提示词自动覆盖用户选择。仍使用用户原有的 Codex 生图入口或自行配置的 GPT Image API；选中选项、浏览和预览不会消耗模型额度。

## 对齐

旧版直接相信模型按要求生成照片开口。实际测试的 PNG 开口比要求窄，造成一边有缝、一边切图。新版首次加载时检测 PNG 中央真实闭合透明区域，缓存开口位置；合成按实际开口贴合照片四边。原画布比例使用连续的分段映射，避免长线条跨转角时出现台阶。改变画布比例时保留边框各分区图案的比例并铺满，部分装饰可能裁切。照片始终完整保留。

开口识别只处理最多 2048×2048 的素材，临时检测内存上限约 20 MiB，检测结果与 PNG 缓存共用生命周期。新生成的整幅边框必须具有可识别闭合开口，开口以外额外全透明斑块不超过外框面积的 3%；不合格结果明确报错，不允许应用、不自动重试。旧个人模板兼容保留，独立透明 PNG 素材不受整幅边框规则影响。此检查能排除结构错误，不能保证模型的美术质量。
