# 留白 / Liubai 0.9.1

在本机给照片添加边框和个人水印。支持批量导入 JPG、PNG、HEIC／HEIF，另存 JPG 或 PNG。

0.9.1 在“边框模板 → 胶片”增加九款扫描／相纸外框：35mm 全幅、彩负暖边、黑白底片、120 中画幅、16mm、Super 8、暗房接触印样、幻灯片卡纸和拍立得相纸。连同原来的三款，共 12 款胶片、30 款本地模板；扫描颗粒与片边标记可在折叠的细节中调整，照片区域保持原样。详见 [胶片外框说明与参考](docs/film-frames-0.9.1.md)。

0.9.0 精简边框工作流：主界面只保留“边框模板”和“AI 设计”两个入口。胶片边界、黑金底片、暖白相纸等共 21 款本地模板直接预览选用，不调用模型；模板细节和保存／预设默认折叠。AI 不再要求先选风格，以照片和自由描述为创作依据；描述可留空，布局与密度默认交给模型决定，额外限制与生成方式收在“更多选项”。模型连接统一在模型配置中维护；精修仅在已有生成作品时出现。旧版风格设置仍可读取，新请求不会继承隐藏的固定风格限制。详见 [精简说明](docs/simple-framing-0.9.md)。

0.8.2 完善整组拖入：在 Finder 或 Windows 文件资源管理器中多选照片，拖到窗口任意位置即可批量导入。启动载入时先接收并排队，连续拖入的组依次处理；显示本组照片数量、等待状态和导入／跳过数量。重复文件去重，非图片和目录过滤，坏图单独报错。预览原有照片和设置保持不变。

0.8.1 默认使用英文界面；右上角语言图标可切换 English／简体中文，并记住用户选择。已有的语言选择会保留。

0.8.0 增加可先预览再应用的样式选择：本地模板共 19 种，新添摄影画廊、双层卡纸、细线双框、胶片边界、现代色带、几何角构、条纹纸边和拼贴纸角。可调整底色、三种配色、强度、尺寸与边框宽度，默认保留当前比例；浏览不调用模型、不更换当前边框，支持键盘切换及原效果对比。AI 生成另提供 7 种设计语言，以及装饰位置、配色、纸张纹理和补充要求。详见 [样式选择、对齐与验证](docs/frame-styles-0.8.md)。

新版识别生成 PNG 实际的透明照片开口，在原画布比例上连续映射各段，修正开口坐标偏差和转角线条接缝。改变画布比例仍使用等比铺满边框分区，边缘装饰可能裁切。新生成的边框若无可靠闭合开口则明确报错，不允许应用；不会自动重试。已有模板兼容保留。模型生成不保证美术质量，干净精确的装帧可直接选择本地样式。

0.7.0 新增“整幅艺术边框”：模型参考照片的主题、色彩、构图和实际留白，生成完整插画，而非只返回几条线或一小簇图标。入口位于“根据照片智能配框 → 艺术边框”，可选择装饰密度和自定义风格；默认使用已登录的 Codex 内置生图，也可使用已配置的 GPT Image API。每次只生成一幅，明确确认后才发送缩略图与消耗所选入口的额度。精修整幅边框会发送照片与当前配框缩略图，重新绘制图案形状、大小和布局。详见 [艺术边框说明与实测](docs/illustrated-frames-0.7.md)。

插画只在留白中合成，照片区域始终保持原样；保存为个人模板后可离线复用。原比例使用连续映射避免拼接细缝；切换比例时按四边与四角等比铺满，边缘插画可能裁切，照片完整保留。线条与几何方案、独立手绘素材仍保留。系统凭据读取有 8 秒等待上限，并限制为一个未完成读取；系统授权异常时显示可恢复的错误，避免连接检查无限转圈。

0.6.4 的“精修一次”支持改动曲线控制点、图案形状/大小/旋转/位置与整体布局，也可精简或补充少量装饰。模板线条展开为可编辑矢量，PNG 保留原素材并调整锚点、大小、不透明度与翻转。界面增加四个调整方向及前后对比；只有用户选择应用后才替换当前设计，支持撤销及保存模板。详见 [精修说明与真实验收](docs/refinement-0.6.4.md)。

0.6.3 在窗口右上角新增独立“模型配置”，没有照片也能设置。参考 Pi AI 的服务商适配方式，按需使用本机 Pi SDK 接入 OpenAI / ChatGPT、Claude Pro / Max、GitHub Copilot 的订阅授权，以及 OpenRouter 的账户余额授权。可搜索支持图片输入的模型，保存为照片分析与精修入口；手绘图像单独设置，默认仍使用本机 Codex。Pi 与 Node 不随应用打包，普通加框无需安装。详见 [模型配置说明与验证边界](docs/model-configuration-0.6.3.md)。

2026-11-15 后续真实验收：用户明确授权后，使用现有 Pi/OpenAI 订阅与 `gpt-6.1-sol` 完成一次智能配框和一次精修。合成测试图返回三套设计，选第二套精修得到一套结果；调用约 52.1 秒与 9.3 秒，四张 PNG 均验证原图区域像素未变。详见 [真实调用记录与效果限制](docs/live-openai-0.6.3.txt)。本次验证仅覆盖当前账户与模型，不扩展为所有服务商或所有模型可用。

0.6.2 的原生 ChatGPT 官方账户授权入口保留，位于“模型配置 → ChatGPT · 官方账户授权”。支持多个账户、刷新和断开，凭据保存在系统凭据库。详见 [原生账户授权说明](docs/chatgpt-sign-in-0.6.2.md)。

0.6.1 的直连 GPT Image API 入口保留：填写自己的 API Key，选择图像模型、质量和素材尺寸，使用该 API 项目的额度。Key 仅保留在本次内存，与 ChatGPT 账户授权和本机 Codex 登录分开。详见 [GPT 生图模型接入说明](docs/gpt-image-api-0.6.1.md)。

## 使用

1. 打开桌面版，在 Finder／文件资源管理器中多选一组照片并拖入窗口任意位置，或点击“添加照片”多选文件。
2. 选择最终比例，调整边框百分比和颜色。可选 18 色色盘、自由选色或照片滴管；滴管保留左侧 6× 原像素放大镜，并在鼠标旁实时跟随。照片完整保留，不裁切、不拉伸。
3. 按需开启文字水印或透明 PNG 水印，可设置位置、大小、透明度；高级设置默认折叠。内置思源黑体、站酷小薇、马善政三种中文字体，也可搜索本机字体或导入 TTF／OTF／TTC；选中字体后按 ↑ ↓ 切换。水平、垂直滑块按原图像素微调位置。
4. 选择输出目录，点击批量导出。失败项可单独重试，取消后可继续未完成任务。

边框百分比表示每侧最少留白占原照片短边的百分比。例如，4000×3000 照片选择 5% 边框，自动模式导出 4300×3300；选择 1:1 则补边为 4300×4300。指定最终比例可能使上下或左右边框更宽。

默认 JPG 质量 95，保留照片像素；高级导出可选择 PNG 或限制最终长边。导出统一为 SDR sRGB，不保留位置等原始元数据。HEIC 读取静态主图，不保留 Live Photo 视频或 HDR 增益图；不支持的 HDR 编码会明确报错。

原图不会改动。输出文件名以 `-framed` 结尾，同名自动编号。下边框放不下水印时会提示调大边框或缩小水印。

## 从源码运行

需要 Node.js 22+、Rust stable，以及平台编译工具。Mac 需要 Xcode Command Line Tools、CMake、pkg-config；Windows 需要 Visual Studio C++ Build Tools、Git、CMake 和 WebView2。

```sh
npm ci
npm run desktop
```

开发运行前须保证 `libheif` 和 `libde265` 的开发库可被 pkg-config（Mac）或 vcpkg（Windows）找到。Mac 可用 Homebrew 安装开发依赖，交付的应用本身不需要 Homebrew。

## 构建与检查

- Mac：`bash scripts/build-macos.sh`，构建仅包含 HEIC 解码所需原生库的桌面版，并将依赖放入应用包。
- Windows：在 PowerShell 执行 `powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1`。脚本安装项目目录内的 vcpkg 解码依赖，生成 NSIS 安装包。
- 界面检查：`npm run check` 与 `npm run build`。整组拖入的隔离回归可在运行 Vite 后执行 `ego-browser nodejs < tests/ui/drop-acceptance.mjs`；该测试模拟系统拖放事件与本机调用，不等于实机系统拖放验收。
- 精简工作流隔离验收：运行 Vite 后执行 `ego-browser nodejs < tests/ui/design-acceptance.mjs`（模拟模型回复与本机连接，不使用真实额度）。
- 核心测试：`cargo test --manifest-path src-tauri/Cargo.toml --lib`。
- 可选 Pi 适配器与启动测试：`node --test tests/pi-bridge.test.mjs tests/startup.test.ts`（Node 22.18+ 的内置 TypeScript 支持；测试使用隔离假 SDK，不读取实际 Pi 凭据或调用模型）。

Windows 安装包的实际构建和运行状态以交付的验收说明为准；提供构建脚本不代表已经通过 Windows 实机验证。

## 项目结构

- `src/`：桌面界面和 Tauri 调用。
- `src-tauri/src/`：尺寸计算、统一图片与文字合成、批量队列和持久化。
- `src-tauri/resources/`：内置中文字体及许可证。
- `scripts/`：可复现构建、打包和合成测试数据生成。

界面预览由与导出相同的 Rust 核心生成。应用使用系统数据目录保存设置、预设、边框模板、导入记录和未完成队列，常规加框全程在本机处理；智能配框仅在用户确认后发送所展示的缩略图。

## 内存与交互

- 预览缓存一张原图及最长边 2048 px 的代理图；快速修改只保留最新预览和保存任务，取色请求也限为一项运行、一项等待。
- 原生图片操作串行；解码与合成前按 1 GiB 工作缓冲预算检查，单文件上限 128 MB。过大的源照片会提示缩小；过大的成片可在导出设置中限制长边。预算不是整个进程或系统内存的硬上限。
- 成片直接合成 RGB，避免同时保存 RGBA 与 RGB 两张全尺寸画布；输出 PNG 也会把透明照片合成到所选边框色上。
- 取色读取已纠正方向并转换至 sRGB 的原图，排除边框和水印。Tab 可聚焦取色区域，方向键移动 1 像素、Shift + 方向键移动 10 像素，Enter 取色、Esc 退出。
- 偏移以锚点位置为起点，正数向右、向下。每张照片单独检查边界，水印超出照片或下边框时明确报错，不会自动裁掉。
- 内置中文字体会补齐所选字体缺少的中文；首版仍只有常规字重。系统字体只在本机复制保存，不随源码包分发。

## 简约纹样与模型配框

“简约花纹”内含纸感、亚麻、点阵、细条纹、柔波纹和角标，可调整强度、大小与颜色。原生核心只绘制边框，预览和导出采用相同几何定义，蒙版仅占 64 KiB。

“根据照片智能配框”默认检测本机 Codex CLI，复用现有登录；也可填写 OpenAI 兼容视觉接口。用户先看到最长边 768 px 的等比缩略图，主动确认后才生成三套建议。在“AI 设计 → 更多选项 → 可编辑线条与图形”中输入设计方向，可留空由模型依据照片自主设计，也可指定装饰密度。建议包含白名单内的配色、边框百分比、基础纹样和有界的贝塞尔曲线/手绘图案场景；本机完成绘制，选用方案后可撤销。

Codex 使用 `codex exec --ephemeral --sandbox read-only --ignore-user-config`，关闭命令执行、额外图片读取、多代理和网页搜索；在临时目录传入缩略图及 JSON Schema，结束后清理。可指定模型和 Codex 可执行文件。需要支持这些选项的 CLI；本机验证版本为 0.169.0-alpha.11.1。CLI 本身不随安装包打包。这里复用现有账户登录，推理仍由所连模型服务完成；没有直接控制 Codex 桌面窗口，也没有显式调用设计 Skill。

通用 API 使用 Chat Completions 图片输入格式（`image_url` 的 Base64 JPEG），要求支持 `max_tokens`。API Key 只保留于应用本次内存，不写入配置、预设或日志；Base URL 与模型名可保留。远程接口使用 HTTPS，本机可使用 HTTP localhost。请求不自动重试，支持取消；取消不保证服务商已经停止计算或免计费。

Codex 非交互与登录说明：https://learn.chatgpt.com/docs/non-interactive-mode
视觉输入说明：https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat

本地样例：`verify_art` 默认只导出六种纹样；明确传入 `--live` 才会把程序合成的测试图交给 Codex。请勿在无人确认的普通回归测试中启用该选项。

## 查看与设计

- 主图上方可直接输入 0.5%–400% 缩放，用滑块/滚轮连续调整；拖动平移，适应恢复全图。聚焦照片视图时 +/− 缩放、0 适应、1 为 100%，方向键平移。缩放不请求重新加框。
- 水印下方“水印细节”显示水印周围真实照片、边框、花纹与艺术图形，使用与导出相同的字体与位置核心。100% 表示把整个局部区域完整放入窗口，不是原照片的 1:1 像素；200%/400% 可拖动查看。浮窗打开时右侧仍可编辑字体、字号和偏移，预览实时跟随，也可切换整体构图。局部图最多 1600×900，不创建整张导出画布。
- 水平/垂直滑块根据当前水印和区域限定可用范围；数字仍可精确编辑，越界会报错。“贴近下沿”把水印放到区域下沿。
- 取色仅在激活时加载一张 ≤2048 px 的代理和最多三块 544×544 原像素图；移动按动画帧更新两个放大镜，确认时只取一次原像素。退出即释放前端缓存。
- 文字位图缓存总计不超过 16 MiB，艺术图形按 256 px 小块绘制；Rust 图片缓冲使用 mimalloc 减少连续大图导出的空闲大块内存驻留。内存预算不是整个进程/WebKit的硬上限。
- 工作区启动只恢复应用本地的缩略图缓存，不逐张打开原图；即使原图等待磁盘、云端下载或文件权限，也不会挡住设置和模板库。旧版本缺少缓存时，首次成功预览后补齐。移除照片时同时清理对应缩略图；缓存与导出队列分开，避免每次写入整批缩略图。
- 载入工作区超过 20 秒会显示可重试提示，保留已有记录；不会为超时自动重复保存、导出或模型请求。启动行为回归：`node --experimental-strip-types --test tests/startup.test.ts`。

- 右上角可切换中文 / English，语言选择在本机记住；用户署名、文件名、模板名称和自定义设计要求保持原文。
- “保存当前边框为模板”或生成方案下的“保存为边框模板”可创建模板；“我的边框模板”在重新启动后仍可使用。模板只保存最终比例、边框百分比、配色、纹样和艺术场景，不保存照片、署名、字体文件或模型凭据。应用模板保留当前水印和导出设置，不调用模型。
- 参数配框向模型提供实际最终画布和照片矩形，保留当前选定的比例与最小边框；纯线条方案无需加入卡通图案。一次生成三套参数，不会自动循环评审。0.6 设计模板按真实留白重排，手绘 PNG 支持六个边框锚点；旧版无参考尺寸的场景保持原绘制方式，部分图案可能被照片蒙版遮住。

交互回归位于 tests/ui/interactions.html（本机模拟原生调用，只验证前端交互）。固定时间的更新次数会受浏览器后台节流影响，不能用作 Mac 实机帧率保证。原生压力回归使用 examples/stress_render.rs：60 预览、60 精确取色、120 块取色图、30 次水印细节、24 次 JPG/PNG 导出；--art 可加载 verify_art 的合成图设计 JSON，原图保持不变。

## 艺术模板与图像生成

“边框模板库”新增 11 套本地设计模板，四类筛选。新模板按真实留白重排，图案等比缩放；保留当前最终比例。旧版无参考尺寸的场景保持原绘制方式。调整区可修改三色配色和装饰强度。

“生成手绘素材”提供本机 Codex 和 GPT Image API 两种入口。Codex 调用 CLI 内置 image_generation 工具，复用现有登录；直连 API 使用独立 Key 和所选图像模型，通过 Images API 生成或按参考图编辑。两者每次都只请求一张透明 PNG，默认仅发送设计方向，照片参考默认关闭。素材保存在应用数据 assets，配框、缩放与批量导出均不触发二次生成。支持上/下六个锚点、等比大小、透明度和水平翻转，可保存个人模板。

“精修一次”展示不含水印的成品缩略图，用户确认后发送原图缩略图与当前配框，调用模型一轮。调整现有模板的颜色和强度，或手绘 PNG 的位置/大小/透明度；不会重绘 PNG 像素，不会自动反复生成。先看结果，再应用或保存；应用后可撤销。

详见 [0.6 设计与 Codex 方案](docs/art-direction-0.6.md) 和 [0.6.1 直接生图接口](docs/gpt-image-api-0.6.1.md)。本地验收：`cargo run --manifest-path src-tauri/Cargo.toml --example verify_designs -- /绝对/输出目录`；只有明确加 `--live-refine` / `--live-image` 才使用 Codex 额度，默认不联网。0.6.1 的 API 回归使用本地模拟服务，没有消耗真实图片 API 额度。
